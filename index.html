The shared brief

Prompt

Create a single-file HTML page (index.html) with all CSS and JavaScript inline and zero external assets. Render a dark, atmospheric hero scene featuring a single, steaming bowl of vegan ramen as the sole visual focus. Make the dish feel alive and appetizing — with natural motion, ambient warmth, and interactive response to the mouse. Keep the scene pure (no UI, text, or menus), responsive on all screens, and respectful of prefers-reduced-motion.
About the bench

Same recipe. Different cooks.

Ramen Bench gives AI coding models one identical creative prompt: build a polished, interactive bowl of vegan ramen in a single HTML file.
